# Table 9.8 — Session Connection

> `RFCs/rfc5024.txt` §9.8 (l. ~4543)

## À quoi elle sert

Établir la **session ODETTE** après ouverture TCP/TLS : SSRM, échange SSID, auth optionnelle (SECD/AUCH/AURP), puis état **`IDLESP`** ou **`IDLELI`** pour les fichiers.

| Qui | Chemin typique |
|-----|----------------|
| **Client TCP** (Initiator) | `F_CONNECT_RQ` → `I_WF_NC` → `I_WF_RM` → `I_WF_SSID` → `IDLESP`/`IDLELI` |
| **Serveur TCP** (Responder) | `N_CON_IND` → `A_NC_ONLY` → SSID reçu → `A_WF_CONRS` → `IDLELI`/`IDLESP` |

## États (colonnes de la matrice)

| État | Entité | TCP typique | Description |
|------|--------|-------------|-------------|
| `IDLE` | Session | C ou S | Pas de session |
| `I_WF_NC` | **Initiator** | **C** | Attend `N_CON_CF` |
| `I_WF_RM` | **Initiator** | **C** | Attend **SSRM** |
| `I_WF_SSID` | **Initiator** | **C** | SSID envoyé, attend SSID pair |
| `A_NC_ONLY` | **Responder** | **S** | SSRM envoyé, attend SSID |
| `A_WF_CONRS` | **Responder** | **S** | Attend `F_CONNECT_RS` |
| `WF_SECD` | Session (auth) | C ou S | Tour authentification |
| `WF_AUCH` | Session (auth) | C ou S | Attend **AUCH** |
| `WF_AURP` | Session (auth) | C ou S | Attend **AURP** |

Tableau complet (tous les états §9.3) : [[../09-tables-etats#9.3 — États protocole]].

## §9.8.3 — Prédicats et actions

Texte RFC intégral : [[00-actions-et-predicats#Table 9.8 — Session Connection]].

### Prédicats (P1–P11)

Voir le hub ci-dessus (définitions complètes P6, P7, P8, P9, P10, P11).

### Actions (1–6, locales à cette table)

| ID    | Résumé                                                                                |
| ----- | ------------------------------------------------------------------------------------- |
| **1** | Préparer connexion : `V.Mode`, identifiants, `V.Buf-size`, `V.Caller=Yes`, `N_CON_RQ` |
| **2** | Start timer inactivité                                                                |
| **3** | Remplir `O.SSID` (variables locales)                                                  |
| **4** | Stop timer                                                                            |
| **5** | Négociation SSID → `V.Mode`, `V.Window`, `V.Buf-size`, etc.                           |
| **6** | `V.Challenge` aléatoire (auth)                                                        |

Ex. transition **H** : actions **4, 2, 3** puis envoi **SSID**.
