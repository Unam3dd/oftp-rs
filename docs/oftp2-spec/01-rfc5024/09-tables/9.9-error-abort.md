# Table 9.9 — Error and Abort

> `RFCs/rfc5024.txt` §9.9 (l. ~4719)

## À quoi elle sert

Table **transversale** : réagir aux catastrophes depuis `IDLE`, `I_WF_NC`, `WF_NDISC`, et (via **ESID** dans les autres tables) depuis n’importe quel état actif.

| Client / Serveur | Identique — les deux implémentent la même logique |
|------------------|---------------------------------------------------|

## États couverts

| État | Entité | TCP typique | Contexte |
|------|--------|-------------|----------|
| `IDLE` | Session | C ou S | Pas de session ou déjà fermé |
| `I_WF_NC` | **Initiator** | **C** | Connexion TCP en cours |
| `WF_NDISC` | Session (fermeture) | C ou S | ESID envoyé, attente `N_DISC_IND` |

## §9.9.1 — Matrice

| Événement ↓ / État → | IDLE | I_WF_NC | WF_NDISC |
|----------------------|------|---------|----------|
| `TIME-OUT` | **X** | **X** | **A** |
| `F_ABORT_RQ` | **X** | **A** | **C** |
| `N_RST_IND` | **X** | **X** | **D** |
| `N_DISC_IND` | **X** | **E** | **F** |
| Invalid Buffer | **X** | **X** | **H** |

## §9.9.2 — Transitions

| Code | Actions | Sorties | État suivant |
|------|---------|---------|--------------|
| **A** | — | `N_DISC_RQ` | IDLE |
| **B** | — | `F_ABORT_IND`, `N_DISC_RQ` | IDLE |
| **C** | 1 | `N_DISC_RQ` | IDLE |
| **D** | 1 | `N_DISC_RQ`, `F_ABORT_IND` | IDLE |
| **E** | — | `F_ABORT_IND` | IDLE |
| **F** | 1 | — | IDLE |
| **G** | 1 | `F_ABORT_IND` | IDLE |
| **H** | — | — | WF_NDISC |
| **I** | 1,2 | ESID(R=01), `F_ABORT_IND` | WF_NDISC |

**Invalid Buffer** = commande inconnue (1er octet) → souvent reason ESID `01`.

## §9.9.3 — Actions

| ID | Définition |
|----|------------|
| **1** | Stop timer inactivité |
| **2** | Start timer inactivité |

Détail : [[00-actions-et-predicats#Table 9.9 — Error and Abort]].

Dans 9.10/9.12, beaucoup de cellules **C** → ESID(02) + `F_ABORT_IND` + `WF_NDISC` (voir transition **C** Speaker).
