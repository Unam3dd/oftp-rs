# Table 9.12 — Listener

> `RFCs/rfc5024.txt` §9.12 (l. ~5159)

## À quoi elle sert

Tant que votre entité est **Listener** : recevoir **SFID/DATA/EFID**, répondre **SFPA/CDT/EFPA**, traiter **EERP/NERP**, envoyer **RTR**.

Même code sur client TCP ou serveur TCP — rôle **Listener** uniquement.

## États (colonnes)

> Tous ces états = entité **Listener** (récepteur du fichier). **TCP typique** : C ou S selon le tour.

| État | Entité | TCP typique | Description |
|------|--------|-------------|-------------|
| `IDLELI` | **Listener** | C ou S | Au repos |
| `IDLELICD` | **Listener** → futur Speaker | C ou S | CD reçu, prêt à envoyer |
| `OPIP` | **Listener** | C ou S | SFID reçu, attend `F_START_FILE_RS` |
| `OPI` | **Listener** | C ou S | Réception DATA |
| `CLIP` | **Listener** | C ou S | EFID reçu, attend `F_CLOSE_FILE_RS` |
| `RTRP` | **Listener** | C ou S | EERP/NERP reçu, attend `F_RTR_RS` |

## §9.12.3 — Prédicats et actions

RFC intégral : [[00-actions-et-predicats#Table 9.12 — Listener]].

### Prédicats (P1–P8)

| P | Signification |
|---|---------------|
| P1 | Restart interdit ou mode Sender-only (SFID invalide) |
| P2 | `F_START_FILE_RS` / `F_CLOSE_FILE_RS` positif |
| P3 | `F_CLOSE_FILE_RS(+).Speaker = Yes` |
| P4 | Restart pos RS > SFID |
| P5 | Special logic actif |
| P6 | `Credit_L - 1 < 0` (erreur protocole) |
| P7 | `Credit_L - 1 = 0` → envoyer **CDT** |
| P8 | CRC invalide (special logic) |

### Actions (1–8, 10 — locales à cette table)

| ID | Résumé |
|----|--------|
| 1–2 | Stop / start timer |
| 3 | `F_START_FILE_IND` depuis SFID |
| 4 | `F_EERP_IND` depuis EERP |
| 5–6 | Special logic (enveloppe / décapsulation DATA) |
| 7–8 | `Credit_L -= 1` / `Credit_L = Window` (**CDT**) |
| **10** | `F_NERP_IND` depuis NERP |

> Pas d’**Action 9** dans la RFC §9.12.3.

**Note 1** : le Listener doit renvoyer **CDT** quand le crédit speaker est à zéro (flow control).
